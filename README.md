# The Scenic Inn website

Static website for The Scenic Inn, a family-run bar and restaurant near the Dark Hedges, Armoy.

## Pages
- `index.html` – home page
- `menus.html` + `menus.js` – menus (edit the menu data at the top of `menus.js`)
- `book.html` + `book.js` – booking flow (front end only; connect `submitBooking()` in `book.js` to the backend)
- `styles.css` – all styling
- `images/` – photos and logos
